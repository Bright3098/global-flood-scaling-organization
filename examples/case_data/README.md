# Case Data

These are small real-data subsets copied or converted from the local GPLW workspace for runnable examples. They are not synthetic and are intentionally much smaller than the full research datasets.

- `01_flood_extraction/mogami_302111282214010_daily_ts_1980_1984.csv`: real Japanese daily discharge subset.
- `02_rc_calculation/flood_events__barcoo_blackall_case.nc`: real Barcoo River flood-event time series converted to the NetCDF schema used by the R/C script.
- `03_trend_calculation/barcoo_flood_events_summary_1969_2015.csv`: real Barcoo River event summary subset.
- `04_otsu_like_method/station_area_trend_case.csv`: real station area/trend subset for area-threshold scanning.
